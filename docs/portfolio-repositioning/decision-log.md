Date: 2026-07-15
Decision: Use Node’s built-in test runner for positioning, claim, route, metadata, and ordering invariants; add a post-build export-link verifier.
Reason: The repository had no tests. Focused dependency-free checks provide immediate measurable value without adding a large test stack.
